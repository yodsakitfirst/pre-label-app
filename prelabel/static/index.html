Local packaging OCR

Read Thai and English on product crops. Text overlap ranks a separate candidate list; it does not override the visual export gate or assign SKUs. Unreadable text never rejects a box.

Setup once: python -m prelabel download-ocr. Processing never downloads models.

Every box is attempted up to the limit, in detector order. Skipped boxes and OCR failures are reported. CPU OCR adds processing time.

Conservative by design

Reference-matched mode uses your selected catalogs to gate the main export. Weak target matches, conflicts with excluded products, and likely edge-cut products are omitted from the single ZIP and remain visible in the evidence report. The score cutoff is experimental; interior occlusion and complete-pack boundaries are not verified. Touching standalone products stay separate.
